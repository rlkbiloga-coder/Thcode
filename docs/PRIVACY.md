# Política de Privacidade — Thcode

*Última atualização: 29 de setembro de 2026*

O Thcode é uma IDE mobile open-source que roda **inteiramente no seu aparelho**. Esta política explica quais dados existem, onde ficam e como são tratados, em conformidade com a LGPD (Lei 13.709/2018).

## 1. Princípio central
O Thcode funciona **offline e local**. Não há servidor próprio, não há coleta de dados, não há telemetria, não há cookies de rastreamento e não há contas obrigatórias.

## 2. Dados armazenados (somente no seu aparelho)
1. Arquivos e projetos que você cria — no armazenamento local do navegador (IndexedDB/localStorage)
2. Configurações e preferências (tema, fonte, atalhos)
3. Chaves de API que você mesmo insere (OpenRouter, GitHub)
4. Histórico de chat da IA, se usada

Você pode exportar tudo (backup JSON) ou apagar tudo (Configurações → Restaurar original) a qualquer momento. Desinstalar o app ou limpar os dados do navegador remove permanentemente essas informações.

## 3. Quando algo sai do seu aparelho
Por padrão, **nada sai**. Somente se você ativar expressamente:
1. **IA (OpenRouter)** — mensagens que você envia ao modelo e sua chave de API vão diretamente para openrouter.ai, regido pela política deles
2. **Busca de plugins** — consultas de busca públicas à API do GitHub (api.github.com), sem dados pessoais
3. **Login GitHub opcional** — token gerenciado por você, usado apenas para as operações que você executar

## 4. Crianças
O Thcode é uma ferramenta de desenvolvimento e não é direcionado a menores de 16 anos.

## 5. Alterações
Mudanças nesta política serão publicadas neste repositório com data de atualização.
