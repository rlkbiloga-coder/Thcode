# Contribuindo

1. Fork privado + branch (`git checkout -b feat/minha-mudanca`).
2. Padrão: HTML5 + CSS3 + JS puro ES6+, sem frameworks.
3. Rode `npm test` (`node --check` + `node tests/smoke.mjs`) antes do PR.
4. Sem `TODO`/`coming soon`: entregue funcionando ou simule de forma convincente.
5. UI em pt-BR com subtítulos em inglês, seguindo o padrão atual.
